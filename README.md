# Chetan Patil — Banana Farming UI/UX Portfolio

This is a self-contained static portfolio website built around the story of a farmer's son who understands banana farming and uses technology to solve a real agricultural problem.

## Included
- `index.html` — complete portfolio
- `style.css` — responsive visual design
- `script.js` — mobile navigation + scroll reveal
- `images/` — all 7 uploaded farm photographs

## Main sections
1. Hero / personal positioning
2. My Story
3. Banana Farming Knowledge
4. BananaCare real-world UI/UX case study
5. Research → Define → Ideate → Prototype → Test → Improve
6. Design principles
7. Farm photo gallery
8. Contact
