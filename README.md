## 🌱 Featured Project: BananaCare

**AI-assisted banana plantation health management.**

**The problem:** Farmers regularly inspect plants and leaves, but identifying a disease from visual symptoms is hard, especially when symptoms are subtle or look alike. Late identification means late action and uncertainty.

**The solution:** BananaCare turns a field observation into a guided digital workflow:

- 🔐 **Authentication:** secure registration and login
- 🌾 **Farm management:** organize farms and plantations
- 📷 **Image analysis:** upload a banana leaf image for AI-assisted classification
- 🕘 **Diagnosis history:** keep previous results accessible for reference
- 💬 **Clear feedback:** communicate the result and confidence in a simple format

---

## 🧭 Design Principles

1. **Simple beats clever.** Use familiar language and direct actions.
2. **Context is a feature.** Design for sunlight, mobile use, time pressure and real field conditions.
3. **Show, don't overwhelm.** Prioritize the information needed for the next decision.
4. **Trust must be earned.** Explain what the system is doing and avoid presenting AI as unquestionable.

## 🚀 Getting Started

No build step or dependencies are required.

```bash
# 1. Clone the repository
git clone https://github.com/chetan-patil17/chetan-banana-farming-uiux-portfolio.git

# 2. Move into the project folder
cd chetan-banana-farming-uiux-portfolio

# 3. Open the site
# Double-click index.html, or serve it locally:
npx serve .
# or
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
